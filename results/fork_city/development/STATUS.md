# Engineering pilot — not the final study

These 440 development-only worlds were executed while integration was still
underway. A review then identified inconsistent scoring of scheduled choices
when an agent already held enough grain: a purchase could have no physical
effect, and a verification still incurred a cost. The final engine creates a
decision opportunity only when grain is needed, making recorded choices
consequential and charging every requested inspection.

Preserved for audit; **do not pool these results with the final study**. No
held-out seeds had been run at this point. Final source hashes are recorded in
the later study's `config.json`; the corrected development run uses a new path.
