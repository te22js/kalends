The Commons branch omits one actual accepted allocation and replays the remaining declared commands to the same horizon; the original journal is byte-preserved. Operator checkpoints deliberately expose private state only for audit. The Player controller uses actual disclosed report content.

Exact restart checks preserve each checkpoint. See accepted_journal.json, validated_spec.json, round_history.json, personal_history.json and actual_omission.json under each applicable adapter directory. The Pompeii life also retains six-agent operator decision records.

These artifacts demonstrate causal continuity and a small institutional threshold. They do not validate human learning, general intelligence, subjective time acceleration, an open-ended career system or generated lifetimes.

## Final public projection

The frozen personal_history.json files preserve the earlier projection used during the recorded run; that code path could include canonical initialization account diagnostics. The new final_public_history.json files are the corrected public projections of the same exact state hashes and accepted journals. Actual disclosed documents remain accessible; private NPC records remain outside the Player view.
