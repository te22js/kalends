## Acceptance gates

The baseline walkthrough and independent plan challenge precede substantial code.
Every consequential transaction keeps explicit terms, canonical validation and
at-most-once semantics; free disclosures remain private until the intentional
question is accepted. Participant DOM must not hold lab-only fields hidden by CSS.
Guide completion comes from accepted events; account comparison never implies
proof; known obligations remain visible even when episodic recall is absent.
Existing lives and frozen research are hash/replay-checked, not migrated/reset.
No new map, renderer, provider framework, paid inference, publishing or outreach.

Deliver both runnable journeys, actual full-interface before/after captures,
copy/condition/source matrix, honest failure register, matched measured scope,
exact commands and committed milestones. Automated checks and agent walkthroughs
are engineering evidence only. Human comprehension, enjoyment and learning remain
unmeasured until consenting people test them. Recording availability and remaining
high-severity defects must be stated rather than papered over.

The reviewer requested explicit integration invariants. Implement them as follows:
- Correct shell ownership is `kalends/experience_os/static/product/*`; backend
  facade is `kalends/experience_os/runtime.py`, with guide/cards/history modules
  under that same package. Scene ownership remains `kalends_3d/`.
- Baseline browser is port 8830, Pompeii life `pompeii_5fc571e86fbd`, started at
  Day 1 08:00 with default settings. Measure free Sabina account from conversation
  open, document copy, and Observatory report separately; report costs/clicks,
  not inferred comprehension. Match camera, moment and viewport where feasible.
- Direct observation is an explicit server-checked whitelist with zero payment,
  time advance, obligation and irreversible onward sharing. It executes the
  same permitted canonical action, with receipt identity and retry reconciliation.
  No label-based client bypass. Everything else retains the review contract.
- Same life keeps iframe identity and tab-local draft values across notebook/
  history/lab navigation. Test pending work and two adjacent lives. Validate
  same-origin/frame/life messages and remove private lab DOM on exit.
- Test return dialogue against real retained accepted evidence and a separate
  execution omitting the originating choice. Never infer recall from global
  history or an institutional obligation alone.
- Explicit additional gates: open-round zero-promise rejection, closed-round
  rejection separately, guide off/resume, deliberate deadline crossing, known
  report age, and honest screen-reader scope. Frozen hashes before/after debug;
  any debug intervention remains exposed development evidence, never held-out.
