# Experience OS: measured results and limits

This is an engineering prototype and an exploratory simulation program. It has
two different executable domains, versioned personal histories, bounded minds,
and evidence-based debriefing. It has no human learning, retention, commercial,
or subjective-time result. All experiments in this phase ran offline.

## Persistent cognition

The current executed study is [cognition V2](../../results/experience_os/cognition_v2/REPORT.md).
It preserves [V1](../../results/experience_os/cognition_v1/REPORT.md), which ran
before the Commons project/opportunity/testimony corrections. Neither version
is a held-out benchmark or independent replication. Each directory contains its
protocol, source hashes and frozen source archive, raw worlds, admitted input
streams, summary and arithmetic cross-check.

V2 executes **972 one-day worlds**: nine authored task families × twelve paired
seeds × nine arms. The families cover stale and contradictory information,
strategic withholding, correlated reports, a 900-minute absence, promises,
changed goals, forgetting/recovery and a delayed hidden transition. The arms are
V2 and V3 with recency, salience, goal and hybrid retention, plus lexical BM25
over FIFO-retained episodes. Capacity is 16 records and retrieval context is
four records. The record limits match; serialized bytes and V3's separately
bounded four-plan register do not. Maximum one actual paid recheck is allowed
before a final allocation. Its new observation and resource cost are outcomes,
not secretly matched exogenous information.

These are actual allocations and scheduled settlements in the existing
Commons domain adapter. Background autonomous teams are disabled for this
controlled comparison. Primary quantities are completed projects, kept/missed
promises, unused capacity and inspection fees. The weighted score is exploratory.
Raw records include admitted-stream hashes, decisions, allocations, delivered
units, conservation totals, and executed ledger hashes. Intervals resample
paired seed clusters; the nine authored templates remain a small shared source
of task structure.

**V3 did not beat its matched V2 arm. All 432 pairs tied on primary outcomes
and executed ledger hashes.** Persistent plans provide an inspectable lifecycle
and explicit revision mechanism, but these tasks did not demonstrate an outcome
benefit. Exact ties and zero-width outcome intervals do not establish general
equivalence. V3 adds roughly 1.21–1.23 KB of serialized state per mind in V2. Short
per-case timing probes show overhead and are descriptive, not controlled latency
measurements.

Retention did matter in two authored families: salience, goal and hybrid arms
preserved a consequential promise or avoided a paid recheck that recency and
FIFO/BM25 lost. Project totals tied across arms. The current report contains the
exact counts and paired intervals. This supports a narrow claim about retention
in these tasks, not emergent society, long-horizon intelligence or a new frontier
memory method. The unknowable delayed hardware transition remains a negative
case; a later failure is not automatically a memory defect.

BM25 is lexical retrieval. No dense embedding endpoint or locally provisioned
embedding model was used. MemoryArena, AMA-Bench, Mem2ActBench and Hindsight are
literature comparators, not implementations reproduced here. In particular,
[AMA-Bench v4](https://arxiv.org/html/2602.22769v4) includes downstream execution
experiments: memory-to-action evaluation is not a new idea introduced by Kalends.
The verified primary literature and mechanism-level comparisons are in
[the thesis](COMPANY_AND_RESEARCH_THESIS.md).

## Temporal fidelity and cost

The current temporal study is
[temporal V2](../../results/experience_os/temporal_v2_20261024/summary.json).
It adds explicit projections of actual active V2 cognitive beliefs and actions
to the earlier [V1 measurement](../../results/experience_os/temporal_20261024/summary.json).
V1 is preserved rather than retroactively replaced.

Two preserved economic worlds, Pompeii and Rebirth with active V2 minds, run for
30 and 90 days with three paired seeds. Four methods yield 48 cells: minute
reference, existing exact event scheduling, a naive 60-minute coarse baseline,
and conservative adaptive scheduling. Each cell has three timed runs and one
separately traced allocation run: **144 timed and 48 traced worlds**. Timed
runtime and Python allocation peaks are separated. Projections include events,
canonical state, commitments, relationships, beliefs, decisions, executed
actions and aggregate outcomes. Source hashes match before and after execution;
all repeated projections are deterministic.

| Method | Full projection match against reference | Group median speedup | Important result |
|---|---:|---:|---|
| Existing exact scheduling | 12/12 | 0.998–1.139× | Fewer empty clock visits; same tasks and consequences |
| Conservative adaptive | 12/12 | 0.983–1.148× | Zero economic tasks coalesced; no established added speed advantage |
| Naive coarse scheduling | 0/12 | 1.094–1.199× | Timing and histories diverged; not a faithful substitute |

The coarse baseline changed the active cognitive beliefs and selected actions
in all six Rebirth cells. Its terminal aggregate economic/batch outcomes still
tied, as did the measured legacy action sequences. Thus matching a final cash or
production total can hide cognition/history divergence. Missing full records and
missing semantic-effect records are reported separately; timestamp differences
must not be described as whole deleted economic events.

The new temporal facade implements LIVE, COMPRESS, MONTAGE and SKIP over the
existing EventClock. Adaptive coalescing is allowed only for explicitly declared
unobserved, idempotent presentation tasks without semantic reads, writes or
successors. Unknown tasks refine exactly. Audit checks detect undeclared ledger,
scheduling or semantic effects; the facade stops on a contract violation. It
cannot undo arbitrary side effects of a malicious handler. The experience
runtime executes commands on a trial copy and commits only after persistence,
providing a separate transaction boundary for supported worlds.

No preserved economic task qualified as cosmetic. A synthetic test proves the
contract can coalesce an allowed presentation example; that is not evidence of
world-scale savings. Two additional compiled-world integration checks match
complete state/ledger hashes across minute LIVE, exact compression and adaptive
compression over seven days, including all six V3 Pompeii minds. They are
correctness checks, not additional timed speed studies.

MONTAGE selects literal consequential events from an explicitly allowed set,
restores chronology and keeps source IDs. It does not summarize skipped time
into invented biographies. Significance conservatively includes resources,
obligations, beliefs, goals, institutions, relationships and opportunities.
Selection is necessarily incomplete; the authoritative history remains available.

## Persistent lives and counterfactuals

The [recorded-life experiment](../../results/experience_os/life_v1/summary.json)
uses the same compiler, runtime, ledger, account projection, minds and scheduler
as the interface. Its actual accepted journals, validated specs, personal
histories, operator checkpoints, frozen sources and omission replay are retained.
The appended `final_public_history.json` files apply the corrected participant
account redaction to the same exact saved worlds. Earlier frozen projections
and explicit operator checkpoints are preserved and labelled; they are not
used as agent memory or as evidence supplied to optional models.

The Commons run recorded **90 days, 360 accepted commands, 1,544 ledger events,
228 completed projects, 89 kept promises and one missed promise**. All 48
credits were conserved; 24 inspection credits moved to the consortium. It
completed exact restart checks at days 1, 30, 60 and 90. Omitting allocation
command 2 produced 226 projects, 904 executed units and eight unused units,
against 228 projects, 912 units and zero unused units in the original.

The Commons controller repeatedly obtains a legitimate dated report through an
accepted disclosure action, makes a capacity promise, submits an allocation,
then advances to real settlement. It reads the report receipt; private canonical
condition is not a policy input. Its first allocation deliberately overcommits,
and later choices adapt to the disclosed condition. The 90-day trajectory tests
finite credits, successful and failed promises, relationship changes, and the
explicit six-completed-project membership threshold. Removing a real allocation
and replaying the declared continuation tests one intervention while preserving
the original journal and matching its horizon.

The Pompeii run recorded **120 days, 12 accepted commands, 3,234 ledger events
and 720 V3 decisions** (120 per NPC). Final player cash was 11, affiliation was
household client, the four-flour delivery was missed and 120 service minutes
were fulfilled. Days 1, 30, 60, 90 and 120 restarted exactly.

The 120-day Pompeii trajectory accepts and misses a real delivery, then keeps
a separate service agreement. All six agents execute V3 decisions through the
preserved purchasing, inspection, routine and communication rules. Checkpoints
reconstruct the exact saved state. This is persistence of an authored life and
actual economic/social consequences, not a general career, skill-acquisition or
biography model. Long-life operation is distinct from the one-day controlled
cognition study; their evidence must not be combined into a claim of measured
multi-month cognitive superiority.

The inherited Pompeii outcome key `deliveries` counts delivery/commission
settlement records, including missed or zero-unit settlements; it does not count
only successful deliveries. The 120-day demonstration's value of one records
the actual missed four-unit promise with zero flour delivered. Its successful
obligation is the separately recorded 120-minute household service. Use the
commitment statuses, fulfilled quantities and `fulfilled_obligations` alongside
that legacy counter; the frozen experiment and accepted history were not
redefined to make the count look like a success.

An omission holds later declared commands fixed, aligns their recorded times,
and discloses commands that become infeasible. It does not discover an optimal
alternative policy, establish necessary causation, or let a model invent a more
successful life.

## Learning, models and next experiments

LEARN has a specified objective, consequential choices, actual feedback,
accessible evidence, grounded questions, an authored transfer question and an
executed counterfactual retry. Optional model assistance may select supplied
literal clauses and questions. Every such result remains a proposal. No generated
fact becomes truth and no proposed action bypasses the host validator.

Provider tests use deterministic offline paths and injected transport fixtures.
Synthetic token/cost receipts from a wire fixture are not paid usage or a live
model evaluation. The server defaults to offline even if provider variables
exist; explicit configuration still uses the existing permission, price and
budget gates. This phase made zero live model calls.

The next research tests should use independently authored multi-month tasks,
actual competing planners and provisioned modern retrieval, matched bytes/token
and inference budgets, more difficult delayed obligations, and separate task
development/test sets. The temporal program needs a real semantically safe
abstraction that removes consequential work with a measured error budget before
claiming an adaptive speed benefit.

The human program requires randomized active controls, matched exposure,
preregistered transfer scoring and delayed follow-up. Its full proposed protocol
and six-perspective adversarial review are in
[the thesis](COMPANY_AND_RESEARCH_THESIS.md). No humans were enrolled. Ordinary
simulated months are not neurological time acceleration or subjective years.
